# Task 06: Sugestões de Busca (Autocomplete)

## Objetivo
Ajudar o usuário a encontrar o termo certo enquanto digita.

## Requisitos
1. **Gatilho:** Iniciar sugestão após o 3º caractere.
2. **Fonte de Dados:** Buscar nos títulos dos produtos com maior volume de vendas.
3. **Interface:** Exibir o nome do produto e, se possível, a categoria.
   - Ex: Usuário digita "iPh..." -> Sugere "iPhone 15 Pro", "iPhone 14".
